# 📁 Docs — material comum da equipe

## Pesquisa de campo (etapas 1 a 4 do percurso)
- [ ] **Observar:** fotos dos obstáculos e das ruas escuras em `docs/campo/` (sem rostos ou placas identificáveis)
- [ ] **Escutar:** entrevista com uma pessoa real que convive com o problema (`docs/entrevista.md`)
- [ ] **Definir:** cidadão + problema em uma frase (já está na Ficha do [README](../README.md))
- [ ] **Rabiscar:** esboços de telas, fluxo de dados e rede (`docs/esbocos/`)

## Roteiro de entrevista
1. Como é o seu trajeto a pé no dia a dia?
2. O que te atrapalha ou te dá medo nesse trajeto?
3. O que você faz hoje para evitar isso?
4. Já deixou de sair ou mudou de caminho por causa disso? Conte uma situação.
5. Se existisse um app para ajudar, o que ele precisaria ter?

> Registrar só o primeiro nome ou um apelido, com consentimento.
